# Fusion 360 대조표

OpenFusionCAD 의 화면·조작·단축키·명령을 Autodesk Fusion 360(디자인 작업공간, 한국어판, 기본 설정)과 맞춘 기준표.
상태: ✅ 동일하게 구현 · 🟡 일부 구현(차이 명시) · ⬜ 자리만 있음(메뉴에 보이지만 "다음 단계" 안내)

## 1. 화면 구성

| 영역 | Fusion 360 | 상태 |
|---|---|---|
| 응용프로그램 막대 | 데이터 패널(9칸 격자) · 파일(▾) · 저장 · 명령 취소 · 명령 복구 | ✅ |
| 문서 탭 | 문서 이름 + 닫기(✕), 새 탭(+) | ✅ |
| 오른쪽 위 | 확장 · 작업 상태 · 알림 · 도움말(?) · 사용자 이니셜 원 | ✅ (확장·알림은 패널만) |
| 작업공간 | `디자인 ▾` | ✅ (디자인만) |
| 탭 | 솔리드 · 곡면 · 메쉬 · 판금 · 플라스틱 · 유틸리티 · 관리 / 스케치 중 `스케치` 상황별 탭 | ✅ (솔리드·유틸리티·스케치 동작) |
| 솔리드 그룹 | 작성 · 자동화 · 수정 · 조립 · 구성 · 검사 · 삽입 · 선택 (그룹 이름 ▾ 로 전체 목록) | ✅ |
| 검색기 | 문서 이름 v1 › 문서 설정 · 명명된 뷰 · 원점(O, X, Y, Z, XY, XZ, YZ) · 바디 · 스케치, **전구** 아이콘으로 표시/숨기기, ▸ 펼치기 | ✅ |
| 주석 패널 | 캔버스 왼쪽 아래 `주석` | ✅ (접힌 패널) |
| ViewCube | 오른쪽 위, 면(위/앞/오른쪽…) 클릭, 홈 아이콘 | ✅ |
| 탐색 막대 | 궤도 · 다음 보기(Look At) · 초점이동 · 줌 · 맞춤 · 화면표시 설정 ▾ · 그리드 및 스냅 ▾ · 뷰포트 ▾ | ✅ (뷰포트 분할 제외) |
| 타임라인 | ⏮ ◀ ▶ ⏭, 피처 아이콘, **끌어서 옮기는 마커**, 오른쪽 설정 | ✅ |
| 명령 대화상자 | 캔버스 오른쪽, 어두운 제목줄(명령 이름), 입력 행, (i)·확인·취소 | ✅ |
| 캔버스 조작기 | 돌출 방향 화살표를 끌어 거리 변경 + 화살표 옆 값 입력 상자 | ✅ |
| 스케치 팔레트 | 옵션: 선종류(구성) · 다음 보기 · 스케치 그리드 · 스냅 · 프로파일 표시 · 점 표시 · 치수 표시 · 구속조건 표시 / 스케치 마침 | ✅ |
| 마킹 메뉴 | 캔버스 **오른쪽 클릭** → 원형 메뉴 + 아래 넘침 메뉴 | ✅ |
| 바로 가기 상자 | `S` → 명령 검색 상자 | ✅ |

## 2. 마우스 (Fusion 기본 조작 방식)

| 동작 | Fusion 360 | 상태 |
|---|---|---|
| 초점이동 | 가운데 버튼 끌기 | ✅ |
| 궤도 | Shift + 가운데 버튼 끌기 | ✅ |
| 줌 | 휠 (커서 위치 기준) | ✅ |
| 선택 / 추가 선택 | 왼쪽 클릭 / Ctrl·Shift + 클릭 | ✅ |
| 창 선택 | 왼쪽 → 오른쪽 끌기 (완전히 포함된 것) | ✅ |
| 교차 선택 | 오른쪽 → 왼쪽 끌기 (걸친 것 포함) | ✅ |
| 마킹 메뉴 | 오른쪽 클릭 | ✅ |
| 홈 / 맞춤 | ViewCube 홈 / 탐색 막대 맞춤 · F6 | ✅ |

| 키 | 명령 | 상태 |
|---|---|---|
| S | 바로 가기 상자(명령 검색) | ✅ |
| Q | 누르기/당기기 (면 → 면 간격띄우기, 모서리 → 모깎기) | ✅ |
| E | 돌출 | ✅ |
| H | 구멍 | ✅ |
| F | 모깎기 | ✅ |
| M | 이동/복사 | ✅ |
| I | 측정 | ✅ |
| A | 모양 | ✅ |
| V | 가시성 전환 (선택 항목 표시/숨기기) | ✅ |
| J | 접합 | ⬜ (조립 미구현) |
| Shift+S | 스크립트 및 추가 기능 | ⬜ |
| 1 / 2 / 3 | 창 선택 / 자유형 선택 / 페인트 선택 | 🟡 (1 = 창 선택만) |
| Delete | 삭제 | ✅ |
| Esc | 명령 취소 / 선택 해제 | ✅ |
| Ctrl+Z / Ctrl+Y | 명령 취소 / 명령 복구 | ✅ |
| Ctrl+S / Ctrl+O / Ctrl+N | 저장 / 열기 / 새 디자인 | ✅ |
| Ctrl+B | 모두 계산 | ✅ |
| F6 | 창에 맞춤 | ✅ |
| **스케치** L | 선 | ✅ |
| R | 2점 직사각형 | ✅ |
| C | 중심 지름 원 | ✅ |
| D | 스케치 치수 | 🟡 (선택 요소 크기를 값으로 변경, 구속은 저장 안 함) |
| X | 보통/구성 전환 | ✅ |
| T | 자르기 | ⬜ |
| O | 간격띄우기 | ⬜ |
| P | 투영/포함 | ⬜ |
